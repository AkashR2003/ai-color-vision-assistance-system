# AI-Based Color and Vision Assistance System

An AI-powered accessibility system that detects objects and identifies colors for users with color vision deficiencies using Computer Vision and AI.

## Features
- YOLO Object Detection
- AI-Based Color Prediction
- Live Camera Detection
- Voice Assistance
- Adaptive Accessibility Themes
- Large Text Mode
- Detection History
- User Authentication

## Accessibility Support
- Protanopia
- Deuteranopia
- Tritanopia

## Tech Stack
- Python
- Flask
- YOLO
- OpenCV
- Scikit-learn
- HTML/CSS/JavaScript
- SQLite

pip install -r requirements.txt
